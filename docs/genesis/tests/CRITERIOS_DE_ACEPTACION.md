# Criterios de aceptación / pruebas

## Fase 0
- [ ] Git limpio o cambios preexistentes documentados.
- [ ] Respaldo/tag/rama existe y se puede recuperar.
- [ ] Compilación base ejecutada y resultado registrado.
- [ ] Inventario de sistemas reales con rutas de código.
- [ ] Guardados existentes identificados y respaldados.

## Fase 1 — Jugabilidad
- [ ] Crear y abrir perfil existente sin pérdida de datos.
- [ ] Personaje boy/girl con controles web y táctiles.
- [ ] Habitación en 3D navegable; ventana y luces interactivas.
- [ ] Calle con casas modulares, coches, colisiones y objeto interactivo.
- [ ] NPC huye; depredador ejecuta persecución y corte sin gore.
- [ ] M02 esconderse puede superarse y fallarse con reinicio seguro.
- [ ] Dinosaurio no ve a través de pared ni atraviesa casas.
- [ ] Hay amanecer, mensajes ficticios, comida, agua y linterna.
- [ ] Estado M01–M05 persiste tras cerrar y abrir.
- [ ] Guardados antiguos siguen cargando en campaña legada.
- [ ] Escena del mundo antiguo permanece en repo y es accesible desde mecanismo previsto.
- [ ] Gráficos baja/media/alta no deshabilitados.
- [ ] Se registraron FPS reales, dispositivo, resolución y ajustes usados.
- [ ] No se publicaron cambios en producción sin autorización.

## Consideraciones de seguridad
- [ ] Ningún jugador necesita introducir dirección doméstica real.
- [ ] Recursos con licencias comprobadas; OSM acreditado donde corresponda.
- [ ] No hay datasets o modelos extraídos de Google Earth/Maps.
- [ ] No se usa gore o personajes de franquicias cinematográficas.
